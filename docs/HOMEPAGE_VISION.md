# Homepage Vision

## Rejected Direction

以下方向已经明确否决，后续开发不得继续沿用为首页首屏：

- 幻想学校作为首页入口
- 简笔画学校建筑作为 Hero 主体
- 让用户感觉自己在进入一座卡通学校

原因：

- 不够真实
- 容易幼稚
- 容易像儿童教育机构
- 首屏品牌感不足
- 限制后续整体视觉系统

## New Hero Concept

新的首页首屏应围绕以下组合构建：

- Visible Pen
- Italian Italic METC Writing
- Dynamic Gradient
- Ribbon / Flowing Forms
- Educational Motion Elements

核心体验不是“进入学校”，而是“进入 METC 的视觉世界”。

## Hero Narrative

推荐的用户旅程：

1. 进入动态视觉空间
2. 看到一支真实可见的笔
3. 笔在屏幕上写出 `METC`
4. 品牌完成
5. `Maths and Engineering Teaching Club` 出现在下方
6. 动态颜色、飘带、轨迹与教育元素展开
7. 用户继续向下进入真实内容世界

## Animation Sequence

首屏动画顺序应记录为：

1. 背景开始流动
2. 笔出现
3. 笔开始书写 `METC`
4. Logo 完成
5. 全称出现
6. Slogan 出现
7. 场景进入稳定动态状态

约束：

- 总时长不超过 5 秒
- 不阻止滚动
- 不做全屏 loading
- 不在每次导航时重新完整播放
- 首页内容入口必须立即执行客户端路由，不得为出场动画增加固定等待；目标页面的短入场效果由目标页面自身承担
- 非首页资源只在首帧完成并进入空闲期后后台预热，品牌动画不得与全站图片解码争抢主线程

## Logo Design Principles

`METC` Logo 必须满足：

- 意大利斜体方向
- 连写感
- 流动感
- 年轻
- 有真实书写感
- 不是普通电脑字体
- 不是婚礼请柬风
- 不是奢侈品牌风
- 可转为 SVG Path

推荐流程：

1. 用参考字体探索整体气质
2. 抽取字形骨架
3. 手动调整字母连接与收笔
4. 形成独立 Logo Path
5. 为真实书写动画准备路径

## Hero Environment

首屏不能只是一行 Logo 加白底。

可组合的环境元素：

- 多层动态渐变
- 柔和流动色块
- 飘带 / 流体形态
- 数学或工程辅助轨迹
- 光学路径
- 手写辅助线

限制：

- 一切元素都必须服务“笔写出的 METC”
- 不堆砌符号
- 不做游戏化粒子效果

## Transition Into Mid-Page Content

首屏到中部内容必须连续过渡，而不是突然切换到另一套页面。

推荐过渡方式：

- 飘带延伸到下一部分
- 某条线条继续引导滚动
- Logo 缩小并进入顶部品牌栏
- 首屏色彩逐步过渡到纸张、黑板、木质、照片语汇

## What Stays Below The Hero

虽然学校建筑不再作为 Hero，但校园与学校元素仍然保留在中下部：

- 黑板
- 课桌
- 课程表
- 储物柜
- 作品墙
- 便利贴
- 文件夹
- 练习册
- 书本
- 地图
- 拍立得照片
- PPT 投影感

## Content Entrances To Keep

以下内容入口结构继续有效：

- 活动与项目
- 课程
- 学生作品
- 学生声音
- 合作学校
- 社团档案
- 社团灵魂
- 团队

这些入口需要从“幻想学校叙事的一部分”转化为“教育成果展览空间的一部分”。
