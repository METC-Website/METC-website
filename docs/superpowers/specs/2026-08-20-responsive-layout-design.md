# METC 响应式多端适配设计

> 历史设计记录：用于追溯响应式决策，不代表当前待办或资源架构。

## 目标

在不改变电脑端现有视觉和交互的前提下，改善手机与平板端的首页、课程、活动、反馈页面，使内容不横向溢出、文字可读、图片完整、按钮易于触控。

## 范围与设备

- 手机：`max-width: 760px`，重点验证 390×844。
- 平板：`761–1100px`，重点验证 768×1024、820×1180 和 1024×768。
- 桌面：`min-width: 1101px` 保持现有样式，不重排现有视觉；这意味着 1024px 横屏设备明确按平板处理。

## 视觉与交互原则

**视觉主题：**保留 METC 当前的纸张质感、森林绿、珊瑚色和手绘教育插画；小屏通过留白、层级和可读字号传达轻松的编辑式学习氛围。

**内容计划：**

1. 首页：品牌导航 → Hero 主信息 → 主题入口 → 教学/活动/反馈章节。
2. 课程页：页面标题与工具区 → 课程列表 → 课程详情、HTML/PDF/幻灯片预览。
3. 活动页：标题与说明 → 相册列表 → 相册内图片墙 → 图片灯箱。
4. 反馈页：标题与图例 → 反馈节点 → 查看器弹窗。

**交互原则：**

- 手机导航采用品牌/语言第一行、横向可滚动导航第二行；不把导航压缩成不可读的小字。
- 触控目标至少约 44px 高，按钮在手机上必要时改为全宽或纵向排列。
- 图片使用 `max-width: 100%`、合理 `object-fit` 和窄屏专用高度；允许导航栏自身横向滚动，但页面根节点不得横向溢出。
- 弹窗、灯箱和左右切换按钮适配安全区与触屏；尊重 `prefers-reduced-motion`。

## 实现方案

采用“CSS 为主、组件最小调整”的方案：

1. 继续使用现有 `app/homepage.css`、`app/teaching.css`、`app/activities.css`、`app/voices.css`；在已有断点基础上补充窄屏规则，避免重写桌面规则。
2. 仅在确有必要时调整组件语义或增加 class，例如移动导航结构、按钮分组和弹窗可访问性；不复制出第二套移动页面。
3. 将断点规则明确分为 `max-width: 760px` 和 `min-width: 761px` 至 `max-width: 1100px` 两组，使用 `minmax(0, 1fr)`、`clamp()`、`min()`、`max()` 和安全区变量处理尺寸，减少固定宽度。
4. 继续使用现有资源索引和 R2 URL 转换逻辑，不改资源路径模型。

## 页面级改动

### 首页

- 保留桌面 Hero 插画；手机隐藏会遮挡文字的装饰插画，仅保留品牌和主体内容。
- 手机 Hero 使用单列布局，标题、介绍和 CTA 按垂直节奏排列。
- 章节入口、课程手册、课堂照片和页脚在手机上改为单列；平板保持两列但允许内容收缩。

### 课程页

- 标题、筛选/操作区和课程内容在窄屏按单列排列。
- 课程卡片和资源按钮允许换行；PDF/幻灯片预览宽度不超过容器。
- 课程详情的双栏内容在手机堆叠，平板使用可收缩双栏。

### 活动页

- 相册展示在手机使用单列书架布局，平板使用两列。
- 图片墙手机两列、平板三列，并保留原始图片比例。
- 相册展开层和灯箱使用全屏/近全屏布局，按钮避开安全区。

### 反馈页

- 反馈节点在手机缩小并重新分布，避免节点和图例互相遮挡。
- 查看器在手机使用全屏内容区，左右按钮固定在可触达位置。
- 标题、图例和说明文字限制最大宽度，避免长英文溢出。
- 平板保留较宽的反馈节点分布和居中的查看器，节点区域使用可收缩的相对定位，不让图例遮住节点；查看器宽度不超过视口的 92%，左右按钮保留至少 44px 触控区域。

## 验证方案

静态检查与构建：

```bash
pnpm typecheck
pnpm build
```

逐页面检查以下尺寸：

- 手机：360×800、390×844、430×932。
- 平板：768×1024、820×1180、1024×768、1100×800。
- 桌面回归：1101×800、1280×800、1440×900。

每个尺寸检查：页面根节点满足 `document.documentElement.scrollWidth <= window.innerWidth`；导航允许仅自身出现横向滚动；标题不截断、按钮可点击、图片/PDF/HTML 资源返回正常、灯箱/查看器可关闭。

桌面端以本次分支创建前的基线提交 `522861a` 为基准，在 1101×800、1280×800、1440×900 分别检查 `/`、`/teaching`、`/activities`、`/voices` 四页。截图保存到本地验证记录（不提交资源文件），逐页对比布局、字号、间距、导航和交互；只允许新增的手机/平板媒体查询在其目标区间生效。
