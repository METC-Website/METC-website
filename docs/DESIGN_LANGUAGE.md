# METC Design Language

## Core Tone

METC 的正式网站视觉语言应同时具备以下特征：

- Playful
- Editorial
- Expressive
- Colorful
- Layered
- Calligraphic
- Dynamic
- Educational
- Handcrafted
- Modern
- Youthful
- Cinematic

中文可概括为：

- 童趣，但不幼稚
- 高级，但不疏离
- 华丽，但不浮夸
- 教育感明确，但不模板化
- 有手作痕迹，但不是手工课海报风

## Brand Priorities

首页首先应让用户进入 METC 的品牌世界，而不是进入一座卡通学校。

首屏优先级应是：

1. `METC` 品牌识别
2. 书写动作与动态空间
3. 教育气质与内容过渡
4. 中下部的真实成果入口

## Visual Elements To Preserve

以下元素在当前原型中已经证明适合延续：

- 校园物件作为内容入口
- 作品展 / Scrapbook / 照片墙式展示
- 活动档案 / 文件夹 / 文件柜
- 便利贴式学生反馈
- 黑板式社团精神
- 黄昏式情绪收尾

这些元素应保留，但需要更真实、更精致、更系统化。

## Visual Elements To Avoid

后续必须避免：

- 卡通学校作为首屏主角
- 简笔画建筑主导首页
- 儿童培训机构既视感
- 标准 SaaS Hero
- 紫蓝霓虹 AI 产品视觉
- 大面积 glassmorphism
- 模板化 bento grid
- 所有内容统一卡片化
- 婚礼请柬式手写体
- 过于古典或奢侈品化的 Logo

## Color Direction

首屏可使用更大胆的动态色彩，但不应落入常见科技产品语汇。

推荐方向：

- 暖黄
- 橙色
- 红色
- 蓝色
- 绿色
- 米白
- 少量紫色点缀

推荐结构：

- 顶部：动态渐变与品牌色流动
- 中部：纸张、黑板、木质、照片、作品
- 底部：黄昏与情绪收尾

## Typography Direction

正式站点至少应分成两套层级：

- 品牌手写层：用于 `METC`
- 稳定信息层：用于导航、全称、正文、档案说明

`METC` 的字形应是近似独立 Logo，而不是直接使用现成字体。

全站正文仍应保持清晰现代，可继续使用高质量无衬线体系。

## Motion Principles

动画需要服务叙事，不应只是装饰。

原则：

- 首屏动画围绕品牌建立
- 笔的动作必须真实可感
- 背景运动应缓慢且有层次
- 滚动过渡应连续，不突然换景
- 鼠标反馈应克制
- 移动端应重构动画路径，而不是简单缩放桌面版
- 页面导航不得用动画人为阻塞；入口应立即切换路由，目标页只保留短暂且不阻止交互的入场反馈
- 避免大面积、永久运行且持续触发重绘的装饰；Student Voice 等氛围页必须控制无限动画数量
- 页面隐藏或路由切换时暂停非必要动画，恢复可见后再继续
- 尊重 `prefers-reduced-motion`，不能让动效成为理解内容或完成操作的前提
