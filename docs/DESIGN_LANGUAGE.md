# METC 设计语言

METC 的网站是“教育成果展览空间”，不是卡通培训机构、SaaS 产品页或 CMS 后台。所有界面改动应优先保护真实内容、清晰叙事与可读性。

## 视觉基调

- 年轻、鲜明、有手作痕迹，但不过度幼态。
- 编辑式排版、纸张/黑板/档案/作品展语汇与真实照片并置。
- 品牌层强调 `METC` 手写感与流动色彩；信息层使用稳定、清晰的无衬线排版。
- 色彩以暖黄、橙、红、蓝、绿和米白为主，紫色仅作点缀。

## 当前界面约束

- 首页首先传达 METC 品牌与教育成果，再引导到课程、活动和学生反馈。
- 课程、活动与 Student Voice 保留各自的叙事和交互形式；不要把所有内容改成同一种通用卡片。
- 真实照片、作品、课件和学生反馈必须优先于纯装饰插画。
- 移动端应针对触控和狭窄宽度重排，而不是单纯缩放桌面布局。

## 动效与无障碍

- 动效服务于层级、进入感和反馈，不能阻塞导航或内容操作。
- 页面隐藏、路由切换或用户请求减少动态效果时，非必要动效应暂停或弱化。
- 保持文本对比度、键盘可达性、焦点管理和触控目标可用性。
- 不新增全屏 loading、永久高负载粒子、玻璃拟态大面积覆盖或模板化 bento 结构。

界面实现以当前 `app/` 与 `components/` 为准；改动后至少检查桌面和手机上的首页、课程、活动与 Student Voice 页面。
