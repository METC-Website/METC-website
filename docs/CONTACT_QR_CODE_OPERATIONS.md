# METC 微信群二维码运维

二维码由仓库管理员通过控制台更新。发布命令会复制公开展示图、生成带内容哈希的前端配置，并写入明确的失效时间；访客无法使用该管理入口。

## 更新二维码

准备官方、仍有效且获准公开的 JPG、PNG 或 WebP 图片，单个文件不得超过 10 MB。不要上传群成员列表、后台页面或其他无关隐私信息。

默认有效期为上传命令执行后的 7 × 24 小时：

```bash
pnpm contact:qr -- /绝对路径/微信群二维码.jpg
```

管理员可以指定有效天数（1–365 天）：

```bash
pnpm contact:qr -- /绝对路径/微信群二维码.jpg --valid-days 10
```

也可以指定按北京时间计算、包含当天的截止日期：

```bash
pnpm contact:qr -- /绝对路径/微信群二维码.jpg --expires-on 2026-08-30
```

需要精确到时刻时，必须提供带时区的 ISO 8601 时间：

```bash
pnpm contact:qr -- /绝对路径/微信群二维码.jpg --expires-at 2026-08-30T18:00:00+08:00
```

命令会完成以下操作：

1. 校验图片格式、文件签名、大小和未来的失效时间。
2. 将图片复制到 `public/images/contact/wechat-join-qr.*`，并移除上一版本的其他图片格式。
3. 更新 `src/data/resources/generated/contact-qr.json`，写入图片 URL、SHA-256 版本参数、更新时间和失效时间。
4. 保留图片的原始长宽比；图片可包含群名或官方有效期说明。

## 到期行为

前端以 `Asia/Shanghai` 时区展示有效日期。页面打开后会持续计时；一旦到达配置中的失效时刻，即使访客没有刷新页面，也会自动移除图片并显示“微信群二维码已过期，请等待工作人员更新”。图片加载失败时显示独立的暂不可用提示。

`--expires-on` 的日期在北京时间当天 23:59:59.999 后失效。例如 `--expires-on 2026-08-30` 表示 8 月 30 日当天仍可使用。

## 发布检查

1. 运行二维码更新命令。
2. 运行 `pnpm typecheck` 和 `pnpm build`。
3. 在 Join Us 弹窗中确认图片清晰、日期正确，并用手机实际扫码。
4. 提交新图片、`contact-qr.json`、脚本和文档，部署到目标分支。
5. 在二维码满员、提前失效或群链接变化时立即更新，不要等待配置时间自然到期。

二维码属于公开网站资源。命令只更新仓库内的静态文件和配置，不会上传到 R2；部署完成后图片随网站发布。
